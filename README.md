# exporter_excel
Модуль установит необходимый для его работы инофблок.
Привязка инфоблоков производится в выбранные сайты во время установки модуля.

Взаимодействие с функционалом модуля производится по пути: Сервисы - Excel импорт - Страница модуля

Пример xls файла:
```text
**********************************************************************************************************************************************************************
* По дням	Контрагент	Артикул 	Номенклатура	Характеристика номенклатуры	Документ движения (регистратор)	Количество	Сумма продажи в руб. *
**********************************************************************************************************************************************************************
```
Пример использования
``` php
use \Uploading0rders\ClientsHistoryExcel;
use \Uploading0rders\ImportIblockService;
use \Uploading0rders\Mapper\ColumnExcelMapper;
use \Uploading0rders\Mapper\UploadingOrderMapper;
use \Uploading0rders\Processor\InfoblockBatchProcessor;

$inputFileName =  realpath(__DIR__ . '/../upload/clients-history/test.xls');
$logPath = realpath(__DIR__ . '/../upload/logs/import_' . date('Y-m-d') . '.log');
$activeSheetIndex = 0;
$settings = [
    'mode' => 'create',
];
$mapper_xml = new ColumnExcelMapper();
$mapper_loading = new UploadingOrderMapper();

$excel_file = new ClientsHistoryExcel($inputFileName, $activeSheetIndex, $mapper_xml);
$excel_import = new ImportIblockService(39);
$ib_processor = new InfoblockBatchProcessor($excel_import, $mapper_loading, $settings);
$ib_processor->import($excel_file->getRows(605));
```

Для отображения в кабинете пользователя (через устанавливаемый компонент akatan::list.element-bind) необходимо заполнить поле "Связка с 1С" в настройках пользователя для связки организации в выгрузке и пользователя на сайте.

Настройки модуля для импорта хранятся в Сервисы - Excel импорт - Страница модуля.

Вкладки "Параметры продажи" и "Параметры аналитики" - настройки для двух выгружаемых из 1С файлов для xls файлов. Чтобы сохранить настройки необходимо нажать "Применить настройки".

Параметры:
* Путь к файлу импорта - путь к файлу относительно корня сайта;
* Обновлять существующие записи - если записи уже были выгружены ранее, то внесутся изменения. Схожесть формируется путем сложения полей: в файле аналитики "Контрагент" + "Заказ" + "Характеристика номенклатуры"; в фале продаж "Дата" + "Контрагент" + "Сумма продажи" +  "Характеристика номенклатуры";
* Пропускать строки с ошибками - если в процессе импорта произойдут ошибки, в случае включенной опции они будут пропущены;
* Начальная строка - строка в файле, с которой начинаются данные;
* Удалить столбцы - удаляет сдвиг в таблице, если есть;

На вкладке "Параметры загрузки файла" предусмотрели возможность импорта данных из файла форматов XML, XLSX, XLS, CSV на случай, если разово надо что либо выгрузить. После загрузки файла через поле "Выберите файл для импорта" и внесения параметров необходимо нажать на кнопку "Начать импорт" для запуска импорта из данного файла. Сохраняются настройки последнего импорта.

Файл сохраняется по пути
```
Корень сайта + '/upload/<module_id>/'
```

Разработаны четыре Агента для работы в фоне:
```php

// - агент отвечает за импорт из вкладки Аналитика
\Uploading0rders\Services\AgentUploadAnalysis::runImportFile();

// - агент отвечает за импорт из вкладки Продажи 
\Uploading0rders\Services\AgentUploadSale::runImportFile();

// - удаляет все (фалы и разделы) из каталога модуля в /upload
\Uploading0rders\Services\Agent::deleteModuleLoadingFiles();

// - агент связывает еще не связанные данные импорта и пользователя на сайте
\Uploading0rders\Services\AgentBindUser2Order::runBindUser2Order();
```

Создан инфоблок "Служебные -> Записи из Excel", в который производится выгрузка данных.

Чтобы влючилась запись логов при работе модуля, необходимо в каталоге модуля создать катлог log:
```php
/upload/<module_id>/log/
```

ToDo::ломается путь при установке в файле /bitrix/admin/akatan.exporterexcel__general.php
